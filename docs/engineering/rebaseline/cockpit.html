Platform-defining decisions

O que implementation não pode reinterpretar.

Identity

  • Organization = tenant root.
  • Product stays external/source-qualified.
  • Principal kinds = human | automation | system.
  • Principal access eligibility é kill switch D2 independente de Membership.

W4 Access

  • 95 / 95 operations mapped.
  • 29 flat exact Permissions.
  • No manage⇒read, execute⇒read, wildcard ou prefix authority.
  • Physical qualification = server-owned epistemic authority, não Permission.

External systems

  • Consumer owns meaning; adapter owns protocol.
  • 2xx ≠ convergence.
  • Notification triggers authoritative reread.
  • Sankhya = sanctioned API Gateway; no Direct Oracle fallback.

Collections

  • 26/26 List/Search homes.
  • Forward opaque cursor; no total/snapshot lie.
  • Source Product search não cria Product mirror.
  • ListItem é semantic subset.
