### pipeline (bind EXACTLY — one codprod)
`Collect(ctx, codprod)`:
1. **409 guard:** in-process `sync.Map` keyed by codprod. `LoadOrStore(codprod, struct{}{})`; if already present ⇒ return zero summary + `ErrCollectionInProgress`. `defer` delete on exit. (Single-process per IC-03 — no DB job table, no polling.)
2. **Local identity:** `identity.GetLocalIdentity(codprod)`. `ErrProductNotFound` ⇒ propagate (S5 maps 404). Other error ⇒ propagate.
3. **No EAN (EARS):** if `LocalProductIdentity.EAN` nil/blank ⇒ build `MatchDecision` NO_CANDIDATE via `ResolveIdentity(identity, nil, now)` (empty candidates ⇒ NO_CANDIDATE), persist it, summary row `{codprod, NO_CANDIDATE, NO_PRICE_EVIDENCE, blocking NO_CANDIDATE}`, cause `{NO_IDENTITY}`. **Make NO catalog calls** (telemetria zero p/ rota). status COMPLETED.
4. **Search + resolve:** `SearchCatalogByEAN(ean)` → candidates+fetchedAt. `ResolveIdentity(identity, candidates, now)` → decision; persist via `AppendMatchDecision`.
5. **Non-ACCEPT:** decision REVIEW/REJECT/NO_CANDIDATE ⇒ summary row `{decision.Status, NO_PRICE_EVIDENCE, blocking NO_CANDIDATE}`; no catalog-product / offers calls. status COMPLETED.
6. **ACCEPT branch:** `GetCatalogProduct(catalogProductID)`. Then `ListCatalogOffers(catalogProductID)`:
   - `ErrCatalogOffersDisabled` ⇒ persist a MarketAggregate with status NO_PRICE_EVIDENCE (n=0), summary price_evidence NO_PRICE_EVIDENCE + cause `{FLAG_DISABLED}`. (NEVER an empty-sample aggregate; explicit fallback, never 500.)
   - success ⇒ persist offers via `AppendValidatedOffers`; `ComputeMarketAggregate(codprod, offers, ml_catalog_offers, catalogProduct.FetchedAt, now)` → persist via `AppendMarketAggregates`. price_evidence = aggregate.Status (OK/INSUFFICIENT_MARKET/NO_PRICE_EVIDENCE).
7. **Competitive signals (linked listings):** `identity.LinkedListings(codprod)`; for each listing: `GetOwnItemPricing` + `GetPriceToWin` ⇒ snapshot ml_sale_price (from OurPrice), snapshot ml_price_to_win (from TargetPrice), `NewCompetitiveSignal` persisted via `AppendCompetitiveSignals`. (Per D-F4-g: listing sources⇒snapshots.)
8. **ADR-17 failure handling:** any provider read (steps 4/6/7) returning a provider error ⇒ for the affected SOURCE write a FAILED `MarketPriceSnapshot` (price nil, failure_reason set) via `AppendSnapshot`, DO NOT overwrite/delete latest VALID, mark summary `status=PARTIAL`, add cause (`PROVIDER_4XX`/`PROVIDER_5XX`). `ErrRateLimited` ⇒ STOP remaining provider work for this codprod (no retry storm), status PARTIAL + cause. Map provider error class → cause via a small deterministic switch. (For catalog-offers, "FAILED" manifests as aggregate NO_PRICE_EVIDENCE + cause, per D-F4-g — offers have no single-price snapshot.)
9. **Summary:** `CollectionSummary{Status, Decisoes:[one row], Contagens: rollup, Causas}`. `Contagens` = count map over the decision rows by price-evidence/blocking category (keys mirror B.1 lower snake_case: ok/no_price_evidence/insufficient_market/no_candidate/sem_custo). NOTE: SEM_CUSTO is a VERDICT-read concern (cost port), NOT produced by collection — a collection row never emits sem_custo; the counts key exists but stays 0 here (cost is consulted only at GET-verdict time, S4). status = PARTIAL if any provider failure occurred, else COMPLETED.
