### failing_test_first (write these BEFORE the types compile)
Table tests that FAIL first, asserting:
1. Constructors REJECT unknown-as-zero (ADR-17): a nil/absent price/amount stays a nil pointer, never `"0"`/zero-value. A `Money` with empty Amount is invalid, not zero.

3. Exact UPPERCASE enum values only; invalid enum strings rejected.
4. The three verdict-state enums are DISTINCT Go types and cannot be cross-assigned:
   - `match_status` ∈ {ACCEPT, REVIEW, REJECT, NO_CANDIDATE}
   - `price_evidence_status` ∈ {OK, NO_PRICE_EVIDENCE, INSUFFICIENT_MARKET}
   - `blocking_state` ∈ {NO_CANDIDATE, NO_PRICE_EVIDENCE, INSUFFICIENT_MARKET, SEM_CUSTO}
