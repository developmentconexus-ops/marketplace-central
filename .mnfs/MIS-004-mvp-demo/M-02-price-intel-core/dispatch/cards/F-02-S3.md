### behavior contract (bind exactly)
- **Idempotency key** = `(tenant_id, scope, ref_id, source, fetched_at)` — the PK already in `0050`. Append uses `INSERT ... ON CONFLICT (<that tuple>) DO NOTHING`; a duplicate is a no-op success (row count unchanged), NOT an error.
- **Latest-valid** explicitly filters `status = 'VALID'` (exact enum from evidence.go) and `ORDER BY fetched_at DESC LIMIT 1`. FAILED/EXPIRED rows NEVER override a latest VALID. Return nil (`*domain.Snapshot`) / not-found sentinel when none — do not synthesize.
- **Expiry is PROJECTED, not stored** — reads compute EXPIRED from `expires_at` vs the query time; the persistence layer performs NO `UPDATE`/`DELETE` to expire. Series/read paths surface the projected status; the row stays.
- **Tenancy:** every query binds `tenant_id = $1` FIRST (repository holds the tenant, mirror the existing `pricing/adapters/postgres` / `marketplaces/adapters/postgres` `NewRepository(pool, tenantID)` idiom). No query without the tenant predicate.
- **Money = decimal STRING, nullable = unknown (ADR-17):** NULL price columns map to a nil `*Money` (or the domain's nullable money type from evidence.go) — NEVER 0/""/default. Nil in → NULL out; NULL out → nil.
- **Time:** `timestamptz`; preserve `fetched_at` / `observed_at` / `expires_at` exactly (no truncation, no `now()` substitution on read of stored values).
- Use the harness pool boundary `internal/testsupport/postgres.OpenPool(t, tenantID)` in the integration tests (same as the existing integration tests) — do NOT open ambient app config.
