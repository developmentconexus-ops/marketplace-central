### aggregation rules (bind EXACTLY — IC-03:27)
Qualifying offer = ALL of: `Price != nil` · `Price.Currency == "BRL"` · `Condition == "new"` · `MatchStatus == MatchStatusAccept`. (Condition compared as the ML literal `"new"`; if a fixture surfaces another casing, flag — do NOT silently lowercase-normalize beyond trimspace.)
- **Dedupe by seller:** among qualifying offers, for each distinct `SellerID` keep the offer with the LOWEST price (decimal compare via big.Rat; tie ⇒ first by input index). Deduped set `D`.
- **Counts:** `NOffers` = number of qualifying offers (pre-dedupe). `NSellers` = `len(D)` (distinct sellers). [D-F4-a — flag.]
- **Empty (`len(D)==0`):** status `NO_PRICE_EVIDENCE`, `Median=nil`, `MinValid=nil`, `NOffers=0`, `NSellers=0`.
- **Non-empty:** `MinValid` = the exact lowest price string in `D` (an offer's own `Money`, unmodified). `Median` = median of `D`'s prices: odd count ⇒ middle value's exact string; even count ⇒ `(a+b)/2` via `big.Rat`, formatted to **2 decimal places, half-up** (D-F4-b — flag), currency BRL.
- **Status:** `len(D) < 5` ⇒ `INSUFFICIENT_MARKET` (median/min stay populated from the real offers — honest, not nulled). Else `OK`.
- `source` param = the aggregate's source (collector passes `ml_catalog_offers`). Construct via `NewMarketAggregate`; return its error unchanged.

### verdict precedence (bind EXACTLY — first matching rule wins)
1. `Decision.Status != ACCEPT` ⇒ `PriceEvidenceStatus=NO_PRICE_EVIDENCE`, `BlockingState=&NO_CANDIDATE`, `MarketRange=nil`, no `market` input. (No aggregate is consulted — identity blocks first.)
2. ACCEPT, and (`Aggregate==nil` OR `Aggregate.Status==NO_PRICE_EVIDENCE`) ⇒ `PriceEvidenceStatus=NO_PRICE_EVIDENCE`, `BlockingState=&NO_PRICE_EVIDENCE`, `MarketRange=nil`.
3. ACCEPT, `Aggregate.Status==INSUFFICIENT_MARKET` ⇒ `PriceEvidenceStatus=INSUFFICIENT_MARKET`, `BlockingState=&INSUFFICIENT_MARKET`, `MarketRange=`mirror aggregate.
4. ACCEPT, `Aggregate.Status==OK`, `Cost==nil` ⇒ `PriceEvidenceStatus=OK`, `BlockingState=&SEM_CUSTO`, `MarketRange=`mirror aggregate.
5. ACCEPT, `Aggregate.Status==OK`, `Cost!=nil` ⇒ `PriceEvidenceStatus=OK`, `BlockingState=nil`, `MarketRange=`mirror aggregate.
- `VerdictLabel` = nil in ALL five (Q3 — M-07 owns margin labels via IC-04; no margin verdict crosses the M-02 boundary).
- `MatchStatus` = `Decision.Status` always.
- `InputsUsed`: add `"our_price"`/`"target_price"` when the corresponding `SnapshotRef != nil` (source = its `Source` string, as_of = its `AsOf`); add `"market"` when `MarketRange != nil` (source = `Aggregate.Source` string, as_of = `Aggregate.FetchedAt`); add `"erp_cost"` when `Cost != nil` (source = `"erp_cost"`, as_of = `Cost.AsOf`). Never emit a key for an absent input. Map may be empty (non-nil).
