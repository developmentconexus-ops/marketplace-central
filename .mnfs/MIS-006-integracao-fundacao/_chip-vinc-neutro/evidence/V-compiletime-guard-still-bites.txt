PROOF BY CONSTRUCTION — the runtime guard added to `decidingAnchors` did NOT weaken the
compile-time exhaustiveness guard.

The worry (raised as attack #1 of the round-3 gate prompt, and the right worry to have): after
`decidingAnchors` started checking the lookup before calling it —

    const rule = statusDecidingAnchors[candidate.match_status];
    if (!rule) return [];

— can someone add a sixth `ProductLinkMatchStatus` to the SDK and have the build stay GREEN while
the column silently names nothing? That would trade a loud failure for a silent one, which is the
exact defect class this chip was dispatched to fix (QueueRow:159 enumerated a union by string
literal, was type-correct, and was therefore invisible).

Answer: no. The runtime guard sits INSIDE the function; the `Record<Union, …>` annotation on the
map literal is what forces exhaustiveness, and it is untouched.

Proved by construction rather than by argument: a probe was appended to QueueRow.tsx that widens
the union by one member and asks the compiler to accept the existing map as the wider Record.

    type _WiderStatus = ProductLinkMatchStatus | "PENDING_REVIEW";
    const _probe: Record<_WiderStatus, (m: ProductLinkCandidateMatchInput) => string[]> =
      statusDecidingAnchors;
    void _probe;

Command (worktree root, worktree-local node_modules):

    npx --no-install tsc -p apps/web --noEmit

Output, verbatim:

    apps/web/src/pages/vinculos/QueueRow.tsx(508,7): error TS2741: Property 'PENDING_REVIEW' is
    missing in type 'Record<ProductLinkMatchStatus, (matchInput: ProductLinkCandidateMatchInput) =>
    string[]>' but required in type 'Record<_WiderStatus, (m: ProductLinkCandidateMatchInput) =>
    string[]>'.

The compiler names the missing member. A sixth status in the SDK breaks the build exactly as
before.

The probe was reverted in the same command (`git checkout -- apps/web/src/pages/vinculos/QueueRow.tsx`)
and `git status --short apps/web/` came back clean; line 508 exists only in the probe run and not in
any commit. The two guards answer different failures and both are live:

  - compile-time (`Record<Union, …>`): "the SDK grew a status" — build fails, loudly.
  - runtime (`if (!rule)`): "the wire shipped a status before the SDK was regenerated" — one cell
    renders the honest unknown instead of `undefined is not a function` unmounting the queue table.

A compiler cannot see the second one, which is why the first does not make it redundant.
