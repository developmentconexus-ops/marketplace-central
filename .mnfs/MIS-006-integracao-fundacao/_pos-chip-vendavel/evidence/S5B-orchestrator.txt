2. TRI-STATE SURVIVES THE FOLD — the part most likely to be quietly widened
================================================================================
Canonicalizing case and collapsing the tri-state are different operations, and
the ruling permitted only the first. Verified as behaviour, in both directions,
end to end:

  "SIM" (out of domain)  -> stored "SIM"        not translated, not nulled
  " r "                  -> stored "R"
  blank / whitespace     -> SQL NULL            absent stays absent

The round-trip test asserts all three against the DATABASE, not against the
parser's return value. On the Sankhya side canonicalSellableValue maps a
whitespace-only value to nil rather than to the empty string, so the two sources
agree on what absence looks like in the column.

Nothing in the fold decides what a value MEANS. A value outside the domain is
still honest-unknown to the rule, which is exactly ADR-17's unknown side.
