F4 — the compiler names every dishonest seat
============================================

After folding the two ports, "go build ./..." is GREEN — the production wiring
satisfies the whole port on its own, which is the first proof that the split was
not carrying any real optionality.

"go vet ./..." then fails in 10 packages. Every failure is a test double that
claimed to be a catalog source while implementing part of one. Under the old
split each of these compiled: the double satisfied the narrow port, the seat
above it recovered the wide port with a type assertion, and the gap surfaced
only as a runtime panic or a 503 on whichever path happened to reach the missing
method.

This is must-fail 2, restated by the type system — a build error with file:line
instead of an incident.
