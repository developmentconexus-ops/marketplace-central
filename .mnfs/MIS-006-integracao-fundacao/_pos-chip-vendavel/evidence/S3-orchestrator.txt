=== 3. ROOT CAUSE of that flake — pre-existing, NOT caused by S3 ===
query_repository.go: `statement_timestamp() AS queue_read_at`  <- POSTGRES-side clock (container)
chain_query_repository_integration_test.go:74-85:
    before := time.Now()            <- Go HOST clock
    got, err := repo.GetImportChain(...)

    if got.QueueReadAt.Before(before) || got.QueueReadAt.After(after) { FAIL }
The test asserts a CONTAINER clock reading falls inside a HOST clock window (~10ms here). Any

tree run. Observed failure: queue_read_at=...281566 vs upper bound ...2814888 — ~77us late.
Note the precision tell: 6 decimals (Postgres microsecond) vs 7 (Windows 100ns host).
